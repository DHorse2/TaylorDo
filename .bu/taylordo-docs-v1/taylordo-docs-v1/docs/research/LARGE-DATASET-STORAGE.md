# Large Dataset Storage

Large datasets introduce storage organization questions beyond desktop defragmentation.

Relevant questions include:

- How should related datasets be grouped?
- How should hot, warm, and cold data be classified?
- How should physical locality be preserved?
- How should workload characteristics drive placement?
- What parts of TaylorDo's architecture apply beyond Windows desktops?

TaylorDo should not be positioned as a data-center defragmenter without evaluation.

However, the underlying ideas of workload-oriented organization and classification-driven placement may have broader relevance.
