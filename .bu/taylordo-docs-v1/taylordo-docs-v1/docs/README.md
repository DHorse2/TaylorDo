# TaylorDo Documentation

TaylorDo is an open engineering project centered on workload-oriented storage architecture for mechanical hard disk drives.

This documentation supports several audiences:

- Users who want a simple HDD optimization tool.
- Developers interested in implementation and future engines.
- Researchers and educators interested in storage architecture.
- Organizations evaluating mature technology, sustainability, and digital inclusion.
