# Website

The TaylorDo website should present two layers.

## Public Layer

- Download.
- Easy install.
- Quick Start.
- Screenshots.
- FAQs.
- Support.

## Knowledge Layer

- Mission.
- Design Science.
- Storage Architecture.
- History.
- Research.
- Outreach.
- Developer Documentation.

The repository documentation should be treated as the canonical source, with the website publishing or adapting that source.
