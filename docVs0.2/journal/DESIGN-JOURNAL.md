# Design Journal

This journal captures the evolution of TaylorDo's design thinking.

These conversations documented ideas that might otherwise have remained implicit.

Key discoveries included:

- TaylorDo is more than a script collection.
- The project is an open engineering project.
- The architecture is engine-independent.
- The current MyDefrag implementation is one realization of a broader storage model.
- Workload-oriented storage architecture is central.
- Documentation is part of the architecture.
- Evaluation should become a separate major work stream.

## Important Design Statement

The architecture is the product.

The implementation is one realization of that architecture.
