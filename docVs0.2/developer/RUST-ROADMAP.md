# Rust Roadmap

Rust is a potential future implementation language for TaylorDo because it is well suited for:

- Safe systems programming.
- Filesystem scanning.
- Structured classification.
- Cross-platform tooling.
- Long-term maintainability.
- CLI tools.
- Reporting.
- Possible future engine work.

The first Rust deliverable should likely be an analyzer, not an optimizer.

A Linux implementation is possible conceptually, but Linux filesystems, allocation behavior, permissions, online defragmentation support, and mount options differ substantially from Windows and NTFS.
