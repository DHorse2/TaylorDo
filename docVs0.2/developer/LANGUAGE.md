# MyDefrag Language

TaylorDo currently relies on the MyDefrag scripting language.

The language is minimal and domain-specific. It lacks many general-purpose programming constructs such as `if`, `else`, `for`, `while`, user-defined functions, and recursion.

TaylorDo demonstrates that sophisticated architecture can be built through composition, modularity, deterministic execution, and careful classification even when the implementation language is highly constrained.
