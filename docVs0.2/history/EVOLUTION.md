# Evolution of the Project

TaylorDo evolved through several conceptual stages.

1. A practical MyDefrag-based script collection.
2. A scheduled Windows HDD optimization system.
3. A drive-role and volume-category maintenance framework.
4. A VSCodium language and tooling project.
5. A documentation and outreach project.
6. A Design Science knowledge base.
7. A future engine-independent storage architecture.

A central realization is that the architecture can outlive the initial implementation.

MyDefrag is the first engine.

Future Rust, Windows, or Linux implementations may implement the same architecture differently.
