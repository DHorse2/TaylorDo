# Documentation Architecture

The TaylorDo documentation is intended to serve multiple audiences while remaining a single authoritative source of information.

The same documentation will support:

- The GitHub repository.
- The TaylorDo website.
- Academic and educational reference.
- Outreach material.
- Technical white papers.
- Future presentations and publications.

## Collections

### Mission

Explains why TaylorDo exists and the engineering principles that motivate the project.

### Design Science

Documents the engineering, computer science, and storage architecture principles that underlie TaylorDo.

These documents explain *why* the system is designed as it is.

### User Documentation

Describes installation, configuration, scheduling, optimization strategies, and everyday use.

### Developer Documentation

Describes the implementation, scripting language, language extension, architecture, database design, and development practices.

### Historical Documentation

Preserves the history and evolution of the project.

Topics include:

- Matt Taylor
- Jeroen Kessels
- JkDefrag
- MyDefrag
- TaylorDo
- The evolution of storage organization

### Outreach

Documents intended for universities, governments, businesses, chambers of commerce, research organizations, foundations, and other institutions interested in storage engineering.

### Research

Future documents examining:

- HDD architecture
- Storage optimization
- Benchmarking
- Workload analysis
- Sustainability
- Future directions

## Documentation Principles

- Engineering before marketing.
- Evidence before opinion.
- Explain principles before implementation.
- Preserve historical accuracy.
- Write for long-term relevance.
- Make documents suitable for both GitHub and website publication.
- Encourage education and research.
- Keep technical claims verifiable whenever practical.

## Long-Term Vision

The TaylorDo documentation is intended to become more than product documentation.

Its long-term objective is to serve as a comprehensive reference on the engineering of mechanical hard disk optimization, workload-oriented storage organization, and the application of software engineering principles to mature computing technologies.
